# 📊 HR Analytics Dashboard – Employee Attrition Analysis

## 🧾 Project Overview

This project is a **Power BI dashboard** designed to analyze employee attrition within an organization.
The goal is to identify patterns and key factors that influence why employees leave the company.
## 🎯 Objectives
* Analyze overall employee attrition
* Identify departments with high attrition
* Understand the impact of salary on attrition
* Examine the effect of overtime on employee turnover
* Analyze attrition trends based on employee experience (years at company)
* Evaluate employee satisfaction levels
## 📁 Dataset Description

The dataset used in this project includes the following key columns:

* EmployeeID
* Department
* Salary (Low, Medium, High)
* MonthlyHours
* YearsAtCompany
* Satisfaction
* Overtime (Yes/No)
* Attrition (0 = Stayed, 1 = Left)
* 
## 🧠 Key Metrics (DAX Measures)

* **Total Employees**
* **Attrition Count**
* **Attrition Rate**
* **Average Working Hours**
* **Average Satisfaction**

## 📊 Dashboard Features

### 🔹 KPI Cards

* Total Employees
* Attrition Rate
* Average Hours
* Average Satisfaction

### 🔹 Visualizations

* **Attrition by Department (Bar Chart)**
* **Attrition by Salary (Pie Chart)**
* **Attrition vs Overtime (Column Chart)**
* **Attrition by Years at Company (Line Chart)**

### 🔹 Filters (Slicers)

* Department
* Salary
## 📌 Key Insights

* Marketing department has the highest attrition.
* Employees with low salary tend to leave more frequently.
* Overtime has a noticeable impact on employee attrition.
* Employees with mid-level experience show higher turnover.
* Lower satisfaction levels are associated with higher attrition.
## 🛠 Tools Used
* Power BI
* DAX (Data Analysis Expressions)
* Data Cleaning using Power Query

## 🚀 Conclusion

This dashboard helps in understanding employee behavior and identifying key factors affecting attrition.
It can assist HR departments in making data-driven decisions to improve employee retention.
